The third release of zen-review. The reader takes a config file now, for the
things you would want to set once rather than press every run, and it bundles a
syntax style of its own.

## New

- **A config file.** It holds the reader's own preferences: the syntax style,
  the colours the palette is derived from, the hues the added and removed rows
  lean toward, a colour per token over the derived palette, whether diffs open
  side by side, how wide a tab is, whether resolved cards open folded, and the
  release check. Every key is optional. It lives at
  `$XDG_CONFIG_HOME/zen-review/config.json` when that file exists, and
  `~/.zen-review/config.json` otherwise, and `zen-review config path` prints
  which one the reader reads.
- **Nothing in it stops the reader opening.** A key it does not know, or a value
  it cannot use, is named on the status bar and keeps its default. One bad
  colour drops the whole set of colours, because a palette with one missing
  reads as broken.
- **A painted background, if you want one.** `paintBackground` paints the
  background you name, or the one your terminal reports. It is off by default,
  so a translucent terminal stays translucent.
- **A bundled `zen-ink` syntax style.** A dark style that ships inside the
  binary. `"syntaxTheme": "zen-ink"` selects it, and any Chroma style name still
  works.

## Changed

- **`update_check` is now `updateCheck`.** The old name still reads for this
  release, and the status bar names the new key until the file says it. A file
  that does not parse, or has a key the reader cannot read, keeps the release
  check off unless it says `"updateCheck": true`, so a typo never undoes an
  opt-out.

## Install

macOS and Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/praxis-labs-io/zen-review/main/install.sh | sh
```

Windows:

```powershell
irm https://raw.githubusercontent.com/praxis-labs-io/zen-review/main/install.ps1 | iex
```

macOS and Linux on arm64 and amd64, Windows on amd64. Anything else:

```sh
go install github.com/praxis-labs-io/zen-review/cmd/zen-review@latest
```

Already running it:

```sh
zen-review update
```

[Install](https://github.com/praxis-labs-io/zen-review/blob/main/docs/install.md)
covers the requirements, the PATH setup, the launch check and every key the
config file takes, and
[the guide](https://github.com/praxis-labs-io/zen-review/blob/main/docs/guide.md)
covers how a review is kept.

## Known gaps

- No Homebrew tap yet.
- No tree filter.
- Keys cannot be remapped. The config file covers how the reader looks, not what
  the keys do.
- A source build reports `dev` rather than a version. Only a release stamps one,
  and `zen-review update` would replace your build with a release, so upgrade
  from the clone instead.
